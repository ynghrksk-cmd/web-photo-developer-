# Web現像アプリ (web-photo-developer)

Lightroom のような写真現像を、ブラウザの中だけで行う Web アプリです。自己利用専用。

## 使い方

GitHub Pages の URL をブラウザで開き、写真を読み込むだけです。

- 対応入力: JPEG / PNG / WebP、RAW (RAF / DNG / CR2 / CR3 / NEF / ARW / RW2 / ORF / PEF)
  - RAF (Fujifilm X-Trans) と DNG / TIFF 系 RAW (無圧縮・PackBits) はセンサーの生データからデモザイク現像します
  - 圧縮 RAW は埋め込みプレビューで開きます
- 調整: 露光量・ハイライト・シャドウ・白/黒レベル、色温度 (ケルビン入力・スポイト対応)・色かぶり・彩度・色別 (HSL)、トーンカーブ、カラーグレーディング、自動補正、マスク部分補正、スポット修復 / コピースタンプ、トリミング・回転・角度補正
- 複数画像の管理、編集設定のコピー、一括書き出しに対応
- 編集は非破壊です。写真は端末の外に送信されません (すべての処理がブラウザ内で完結します)

## ファイル構成

- `index.html` — アプリ本体 (単一ファイル)
